# Goal 5 - exercise timer

For exercises that have a recordSetsType of TIME or WEIGHT_AND_TIME, eg Plank or Farmer's carry, when the exercise dropdown panel is opened during a session, on each set row, to the right of the dropdowns, show a 'stopwatch' icon (make the target big enough to easily tap eg 40px target area with a 24px square icon) that when clicked, opens a popup / modal with a large timer on it - use the same font as for the session timer, in a big size so easily viewable. 

There should be a large icon button below it for play/pause, and also Finish and Cancel. If Finish is clicked the duration should be used to populate the time inputs in the exercise set row. If Cancel is clicked don't update the inputs.

The timer should have a circular border in --em-accent-teal. Use --em-accent-purple, --em-accent-flat-purple or --em-accent-fuchsia for the button icons and labels.  
When play or pause is pressed, show an animation over the timer eg the play or pause button superimposed and quickly increasing in size / transparency. Keep the animation quick and 'pop' it.
