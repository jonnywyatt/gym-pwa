# Goal 9: exercise muscle group summary

When you view an exercise card, either when building a new routine or viewing an existing one, the cards currently list primary and secondary muscle groups.
Instead, just list the body areas worked, in order of primary | secondary | tertiary.
The card should be tappable, and open the modal component. That will then list out the primary, secondary and tertiary muscle groups.
The same modal should also be available from the in-session page. On the same row as the Add set button for each exercise, but right aligned, add a new button - 'Muscle groups' which should open the same modal.
