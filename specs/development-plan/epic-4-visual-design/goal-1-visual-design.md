# Visual design

I've built a progressive web app, for use on multiple devices but mainly mobile, and mainly for use recording workouts and reviewing workout data.

I have the basic functionality and page components in place but would like a visual design concept and colour scheme.

The app is a gym companion called "Duro" to record workout data while doing the exercises.

Some screens will have lists of items, like routines, exercises or completed workouts. There will be some use of graphs, but not built yet.

The 'in workout' page will be critical functionality. I'll detail that separately. Initially I'm after a visual design concept:
- logo for "Duro"
- colour scheme - I'd like a vibrant, rich combination of colours, maybe a dark but saturated blue or green, with accents of turquoise or lime for contrast. Where there is a lot of detailed numerical data on lists and panels, readability is key so will take advice on whether those lists should be dark text on a light background, or vice versa.
- The feel of the design should be very modern but can have some playful aspects for example the Duro logo could use an expressive modern font, conveying movement and dynamism
- Screens include: workout lists, active workout with sets/reps/weight inputs, timers, exercise lists, a dashboard
- Numerical data density is high — sets × (weight + reps) per exercise
