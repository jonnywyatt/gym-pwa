# Goal 2: Different set types for exercises

Show different types and numbers of default sets during a workout, based on the exercise type.

For exercises with RecordSetsType of REPS, - default to 2 sets, both of type Standard (ie no Warmup set).

For exercises with RecordSetsType of WEIGHT_AND_TIME, default to 1 set of type Standard.

For exercises with RecordSetsType of TIME, default to 1 set of type Standard.
